# 캡처 정리 체크리스트

프로젝트 캡처를 넣기 전에 아래 항목을 확인합니다.

## 캡처하면 좋은 화면

- 메인 화면 또는 첫 진입 화면
- 핵심 기능 화면
- Before/After 비교 화면
- 관리자 페이지 또는 운영 도구
- 결제/구독/정산 관련 화면
- 차트, 지도, 캘린더 등 기술적으로 복잡한 UI
- 에러 처리, 빈 상태, 로딩 상태 등 완성도를 보여주는 화면
- 스토어 등록 화면 또는 출시 증빙

## 캡처 전 확인할 것

- 개인정보가 보이지 않는가?
- 병원명, 고객명, 전화번호, 이메일, 주소가 노출되지 않는가?
- 결제 정보, 계좌, 주문번호, 내부 ID가 보이지 않는가?
- 회사 내부 URL, API Key, 관리자 계정 정보가 보이지 않는가?
- NDA 또는 비공개 약속에 위배되지 않는가?

## 공개 수준 표기

- `Public`: 포트폴리오 웹사이트/문서에 공개 가능
- `Interview Only`: 면접에서 화면 공유 또는 로컬 파일로만 제시
- `Private`: 외부 공유 금지, 텍스트로만 추상화
