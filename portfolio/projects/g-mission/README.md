# G-Mission 국세청 전시 프로젝트

## 기본 정보

- **프로젝트명**: G-Mission
- **기간**: 2019.11 - 2019.12
- **계약/근무 형태**: Flutter 클라이언트 개발
- **공개 수준**: Public 또는 Interview Only 확인 필요
- **도메인**: 공공 전시, iPad/키오스크 앱
- **내 역할**: 국세청 전시용 인터랙티브 Flutter 앱 개발 및 현장 운영 지원

## 이력서용 요약

정부혁신박람회 국세청 전시관 전용 iPad/키오스크 인터랙티브 앱을 개발하고, 현장 운영 안정화를 지원해 금상 수상에 기술적으로 기여했습니다.

## 캡처로 넣으면 좋은 자료

- 전시 앱 메인 화면
- 인터랙티브 기능 화면
- 키오스크/iPad 실제 설치 사진
- 수상 또는 전시 증빙 자료

## 면접 설명 포인트

- 전시 환경에서의 안정성 고려
- iPad/키오스크 UI 설계
- 공공기관 요구사항 반영 방식
