# Motion T Pro 병원 CRM 앱

## 기본 정보

- **프로젝트명**: Motion T Pro
- **기간**: 2024.09 - 2025.04
- **계약/근무 형태**: 프리랜서 Flutter 앱 개발자
- **공개 수준**: Interview Only
- **도메인**: 병원 CRM, Flutter 앱 최적화
- **팀 구성**: 2인 Flutter 개발 체제
- **내 역할**: 상태 관리 구조 개선, 이미지 처리 엔진 재설계, Shorebird Code Push 배포 적용
- **납품/출시 여부**: 실사용자가 있는 베타 버전 출시 지원

## 이력서용 요약

2인 Flutter 개발 체제에서 병원 CRM 앱의 상태 관리 구조와 이미지 처리 엔진을 개선해 실사용 베타 출시를 지원했습니다. Hook/BLoC 혼재 구조를 BLoC 중심으로 정리하고, 약 1분 소요되던 이미지 저장 처리 시간을 4초 이내로 단축했습니다.

## 캡처로 넣으면 좋은 자료

- 이미지 처리 Before/After
- 이미지 저장 완료 화면
- CRM 주요 화면
- Shorebird 배포 또는 버전 관리 증빙
- 상태 관리 구조 설명 다이어그램

## 면접 설명 포인트

- Hook/BLoC 혼재 구조를 BLoC 중심으로 단일화한 방식
- Canvas 좌표 기반 오프스크린 합성 구조
- 약 1분 → 4초 이내로 단축된 이미지 처리 개선
- Shorebird Code Push 실제 배포 경험
